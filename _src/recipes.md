# 复刻配方（每个工具画什么、用什么视觉语言）

通用：复刻区放在 `.stage` 里，宽度自适应、高度 380–560px。用内联 `<svg viewBox>` 或 HTML+CSS 绝对定位均可。背景色、线宽、圆角、字号要贴合该工具，不要所有页长一个样。

## 白板 / 协作类

**miro**（accent #4262ff，浅灰白板底 #f7f7f8）
画一张「产品启动工作坊」白板：3 个手写体标题框（Sticky notes 便签，黄 #fff9b1 / 粉 #ffd6e8 / 蓝 #cfe8ff，轻微旋转 -3°~3°、投影），围绕一个大的圆形 cluster；用粗蓝箭头连接；右下角放一个「Miro 工具栏」浮条（指针/便签/形状/连线/评论/计时器图标）；画 2 个彩色协作光标 + 名字标签（"Yuki"、"Marco"）。点阵网格底纹。

**mural**（accent #ff0066，底色 #fbfbfa）
画「Design Sprint」工作坊：顶部一条横向的 5 阶段流程带（Understand / Sketch / Decide / Prototype / Test），每阶段是一个大圆角矩形区域，内含 3–4 张便利贴；左下角放一个「Voting」贴纸簇（带小圆点票数 3/5/2）；右上角一个 session 头像组。整体比 Miro 更"模板化、分区感强"。

**figjam**（accent #0d99ff，底色 #ffffff）
画「用户旅程地图」：一条横向泳道，上方 5 个阶段列（Discover / Consider / Buy / Use / Renew），下方情绪曲线（手绘感折线 + emoji 节点 😀🙂😐🙁），再下方 sticky notes 簇（FigJam 标志性的亮色便签 + 圆角、粗描边）。加一个 cursor 标签 "Aki" 和一个 stamp（👍）。字体圆润。

**ziteboard**（accent #1a9be0，底色纯白无限画布）
画「在线数学辅导」场景：一块干净白板上手写公式 `∫₀¹ x² dx = 1/3`（用 SVG path 或手写字体近似）、一个手绘坐标轴曲线、一个 PDF 截图占位框（浅灰 + 文件名标签）、右侧一个小 zoom 控件（+ / 100% / −）与协作头像。视觉要"极度干净、线条细、无装饰"，与 Miro 的丰富贴纸形成对比。

**novastart**（accent #6c5ce7，底色 #0f0f12 深色）
画「无限画布 OS」：深色无限画布上漂浮 3 个应用窗口（一个终端、一个浏览器、一个 AI agent 对话面板），窗口有细边框和标题栏；中间用虚线连到一条时间线/版本节点；画 2 个 agent 光标标签（"Claude"、"agent-2"）。整体是"桌面操作系统搬进画布"的观感，霓虹紫强调色。

## 专业绘图类

**lucidchart**（accent #f24726 橙红，底色 #ffffff）
画「订单系统架构图」：标准分层——Client → API Gateway → 3 个微服务（Order / Payment / Inventory）→ 数据库 + 消息队列。矩形直角或小圆角、1.5px 描边、蓝灰色系填充（#e8eef7 / #dbe7f5），连线是正交折线带小箭头，容器用虚线大框标注 "AWS VPC"。字体是干净的无衬线。加一个小 AI 生成提示框浮层（"Describe your diagram…"）。

**drawio**（accent #f08705 橙，底色 #ffffff + 网格）
画「AWS 三层架构」：使用 draw.io 经典形状语言——矩形 + 圆角 0、描边 1px #000、填充白/浅色；节点里放简化云图标（EC2 方块、S3 桶、RDS 圆柱、Lambda λ）；用带折角的正交连线；整体有淡淡的 10px 网格背景；右上角一个形状库面板缩略（Basic / AWS / UML / Network 四组小图标）。

**gliffy**（accent #1f5fbf，底色 #f4f6fa）
画「Confluence 内嵌的流程图」：一个模拟的 Confluence 页面框架（顶部页面标题栏 + 面包屑），中间嵌着流程图——开始/结束用胶囊，判断用菱形，矩形用浅蓝填充，连线细而规整；页面右侧留白。强调"它就长在你 wiki 里"的嵌入感。

**omnigraffle**（accent #2c2c2e，底色 #ffffff，Mac 质感）
画「iOS 应用导航结构」：极其精确、细线（1px）、优雅的节点布局；用浅灰填充 + 深灰描边，箭头是细长实心三角；文字用 SF 风格的小字号；右上角一个 stencil 面板（4 个图形缩略：矩形/圆/菱形/圆角矩形）；整体是"印刷级精度"的观感，与 draw.io 的工具感拉开。

**creately**（accent #7b61ff，底色 #fbfbfd）
画「BPMN 采购审批流程」：泳道（申请人 / 主管 / 财务），BPMN 形状语言——圆角矩形任务、菱形网关（带 ×）、圆形事件（细描边）、虚线消息流；配色用紫/青/橙的柔和填充。左侧一个形状库侧栏（Flowchart / BPMN / UML / Mind Map 标签）。

**moqups**（accent #2f6fed，底色 #ffffff）
画「移动端注册流程线框 + 流程」：3 个手机线框（灰阶占位：状态栏、输入框、按钮），用箭头串起来；下方一条对应的流程图（简化矩形）。线框必须是**灰阶 wireframe 风格**（#eee 填充、#ccc 边框、灰色占位条），这是它和其他工具最大的区别。

**whimsical**（accent #6b4eff，底色 #ffffff）
画「产品流程图」：Whimsical 标志性的"干净到发光"风格——大圆角（12px）、柔和粉彩填充（薄荷绿 #d9f2e6、淡紫 #e8e2ff、浅黄 #fff3cd）、极细描边、无阴影；节点文字短而居中；连线是平滑曲线（贝塞尔）带小圆点端点。整体留白大、呼吸感强。

## 文本即图 / 工程类

**eraser**（accent #22c55e 绿，底色 #0f1115 深色）
画「系统设计文档」：左侧一段文档标题与正文（浅灰小字），右侧深色画布上的架构图——服务用深色卡片（#1a1d23 底、#2a2f3a 边框、圆角 8）、数据库用圆柱、云用虚线大框标注 "AWS"；连线是细青色/绿色带箭头；文字用等宽字体（mono）。强调"图 + 文档同源"。

**websequencediagrams**（accent #1f4e79，底色 #ffffff）
画「大规模时序图」：至少 6 条生命线（Client / LB / Auth / Order / Payment / DB），垂直虚线，激活条（细长矩形），消息箭头实线（同步）/ 虚线（异步返回），带 `loop` 或 `alt` 的框（左上角折角标签）；整体黑白 + 深蓝，非常"工程制图"。

**wiretext**（accent #111111，底色 #fafaf7）
画「Unicode 线框稿」：**必须用等宽字体**，用 `┌ ─ ┐ │ └ ┘ ├ ┤ ┬ ┴ ┼` 画出登录页线框，内部有 `[ 邮箱        ]`、`[ 密码        ]`、`[   登录   ]`；旁边一个浏览器窗口框（`╭─ 标题栏 ─╮`）。可以配一个"源码 / 渲染"切换感的小标签。

## 思维导图类

**xmind**（accent #ff6b35，底色 #ffffff）
画「产品发布计划」思维导图：中心主题（圆角胶囊、深色填充），向左右发散 4–5 条**有机曲线**分支（贝塞尔、粗细渐变），一级主题为彩色胶囊（橙/蓝/绿/紫），二级为纯文字；节点旁加小图标（✓、⏰、⭐）和编号标记。曲线要柔和、有手绘温度。

**mindmanager**（accent #2e6da4，底色 #ffffff）
画「项目 WBS」思维导图：中心主题用矩形（不是胶囊），分支是**直角折线**连接（不是曲线），一级主题带编号 1/2/3，部分节点挂"任务信息"小卡片（日期、负责人）；整体更"企业报表"感，比 Xmind 硬朗。

**mindnode**（accent #ff5a5f，底色 #ffffff，极简）
画「读书笔记」思维导图：中心一个手写感的主题节点，4 条**极细、单色**的分支曲线（同一颜色，仅靠粗细区分层级），节点无填充、只有文字；大量留白；字号层级明显（中心 28px → 一级 18px → 二级 14px 灰色）。整体是"Apple 式极简"。

**milanote**（accent #f5a623，底色 #f6f4ef 米色软木感）
画「品牌项目灵感墙」：一张张卡片拼贴——1 张图片占位（彩色渐变块 + 文件名）、1 张便签（黄色、手写体）、1 个色板（5 个小色块）、1 段文字卡；用细的浅灰曲线箭头连接成"思考流"；卡片有轻微旋转和投影。整体像设计师的实体灵感板。

## UX 规划类

**flowmapp**（accent #2b6cff，底色 #ffffff）
画「电商站点地图 + 用户流」：左侧站点地图树（首页 → 分类 → 商品 → 购物车 → 结算），节点是白色卡片带细边框和页面小图标；右侧用户流（3 个页面缩略 + 菱形判断 + 箭头）；顶部工具栏（Sitemap / User Flow / Wireframe / Content 标签页）。蓝色为主。

**octopus-do**（accent #1b6ef3，底色 #ffffff）
画「站点地图」：横向展开的树，节点是**彩色圆角卡片**（蓝/青/黄/粉，每层不同色），卡片上有页面名 + 一个小图标 + 子页面数量；连线是平滑的直角折线；整体明快、卡片化，比 FlowMapp 更"轻"。

**writemaps**（accent #2f9e44 绿，底色 #ffffff）
画「网站规划地图」：树状节点带**页面缩略图占位**（每个节点是一个小卡片，上半是灰色缩略、下半是页面名 + 备注图标）；左侧一个页面详情面板（标题、备注、内容清单）；强调"给每个页面收集内容"。

**dyno-mapper**（accent #0b5ed7，底色 #f7f9fc）
画「带内容盘点的站点地图」：树状图，每个节点右侧挂**指标徽章**（字数、图片数、可访问性评分 A/B/C 彩色圆点）；右侧一个 "Site Health 82" 的仪表盘卡片 + 问题列表（3 条带严重度色块）。强调"站点体检"。

**overflow**（accent #4f46e5，底色 #0f0f14 深色）
画「用户流程图」：3–4 个**设计稿缩略**（小屏幕卡片，内含灰色 UI 占位）作为节点，用箭头连接并标注动作（"点击购买"、"返回"）；连接线有分支与合并；背景深色，节点白色卡片，箭头浅色细线。强调"从设计稿自动生成流程图"。

## 可嵌入真库

**excalidraw** —— 用 `../assets/lib/excalidraw.bundle.js` + `.css`，页面里放一个 `<div id="root" style="height:520px">`。bundle 已内置一张"API Gateway → Order Service → Postgres"手绘架构图作为初始场景，直接可用。上方或下方配一段说明（它的手绘风格 = rough.js + Virgil 字体）。**不要重复引入 React**，bundle 自带。
注意：bundle 会撑满 `#root`，容器必须给定高度，且该页其余内容在容器外。

**tldraw** —— 用 `../assets/lib/tldraw.bundle.js` + `.css`，同样 `<div id="root" style="height:520px">`，自带完整白板（工具栏、页面、缩放）。说明它的定位：可嵌入的无限画布 SDK，`<Tldraw />` 一行接入。

## AI 生成类

**napkin**（accent #38bdf8，底色 #ffffff）
画「文本 → 视觉」：左侧一段被高亮选中的文字（浅蓝底 `#e0f2fe`，关键词加粗），右侧由它生成的流程图——**柔和粉彩**填充（浅蓝 #dbeafe、浅绿 #dcfce7、浅粉 #fce7f3）、虚线圆角连接、每个节点配一个线条小图标（📄✏️⚡）；背景是极淡的点阵。整体轻盈、非工程感。

**explainviz**（accent #7c3aed，底色 #ffffff）
画「科研图形摘要（graphical abstract）」：左侧实验组（3 个圆形细胞图标 + 箭头），中间机制（分子/通路示意，用同心圆和箭头），右侧结果（柱状图 + 显著性星号 `***`）；配色是学术期刊风（蓝紫 + 橙 + 灰）；外围加一个「Figure 1」标注和比例尺。强调"可导出 SVG、可编辑"。

**yed**（accent #7ab800 亮绿，底色 #ffffff）
画「自动布局的网络图」：30+ 节点密集但**排列极其规整**（这是 yEd 的卖点：自动布局算法）——用分层布局（hierarchical），节点是小圆角矩形，边是带箭头的细线，部分边有标签；左下角放一个 "Layout: Hierarchical / Organic / Orthogonal" 的下拉选择器。整体是"图论工具"的密集感。
