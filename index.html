一张图看清这 30 个工具的位置

横轴是你怎么把图做出来：左边全靠鼠标拖拽，右边全靠打字。纵轴是图有多自由： 下面是空白画布想画啥画啥，上面是被形状库和模板约束住的结构化图。 越靠右下，工具越像"编译器"；越靠左上，越像"纸"。

悬停看一句话定位，点击圆点直接跳到该工具的 demo 页。

按能力家族分组

同一家族内部才是真正的竞品；跨家族比较意义不大——它们解决的不是同一个问题。

自由画布 / 白板

先有空间，后有结构

本质是"无限大的纸 + 一堆便签/图形"。适合发散、工作坊、评审；不适合交付一张需要精确表达的系统图。选型看的是模板质量、协作体验、留存成本，不是画图能力。

结构化绘图

形状库 + 吸附对齐

架构图、流程图、UML、BPMN 的主场。共同点是形状语义化（菱形=判断、圆柱=数据库）、连线自动吸附、对齐辅助线。差别在：精度上限、模板/图标库、以及是否内嵌在你的协作工具里。

思维导图

从中心长出去

只有一个中心主题、只允许树状发散。约束看着像缺点，实际是优点：它逼你想清楚层级。这一族拼的是"输入速度"和"展开/收起的阅读体验"，不是图形丰富度。

UX 规划 / 站点地图

给"网站"画图

专门为"一个网站/产品有多少页面、怎么串起来"服务。比通用绘图工具多了页面层级、内容清单、交付物导出——本质是规划工具，不是画图工具。

AI 生成 / 图文转换

描述 → 图

你把文字或数据给它，它把图还给你。省掉的是"摆位置"这件事。代价是结构精度和可复现性——AI 生成的图很难进版本管理，也很难让三个人画出一模一样的图。

代码即图 / 文本即图

图是源码的副产品

图和代码住在一起：能 diff、能 review、能随代码更新。代价是排版不由你控制，而且非工程师基本用不了。这一族内部的分歧是"语法有多重"。

可嵌入的画布引擎

不是产品，是零件

它们不是给你画图用的，是给你写进自己产品里用的。判断标准完全不同：看包体积、License、数据结构是否可序列化、能不能白标。

横向对比

只看能决定选型的那几个维度。定性判断基于公开产品信息，不作为法律或采购依据。

工具主要产出输入方式实时协作离线/自托管免费可用最适合

「离线/自托管」一栏：桌面应用天然离线；draw.io 有桌面版与自托管；Excalidraw 可自托管；tldraw 提供 SDK。SaaS 型工具的"离线"仅指弱网编辑，不等于数据留在本地。

我要画 X，该选谁

按真实场景给结论，不给"都很好"。

系统架构图，要进文档、要随代码更新
Mermaid 或 Eraser。
Mermaid 免费、GitHub/Notion 原生渲染，代价是排版粗糙；Eraser 图更漂亮、能写文档，但绑 SaaS。
给老板/客户看的一张漂亮架构图
Lucidchart 或 OmniGraffle。
Lucidchart 在线协作、模板多；OmniGraffle 是 Mac 本地应用，精度和排版控制最强，适合交付级。
完全免费、不登录、打开就画
Excalidraw 或 draw.io。
Excalidraw 手绘风格、能自托管；draw.io 形状库最全、有桌面版。两者都不锁你。
团队工作坊、头脑风暴、复盘
Miro / Mural / FigJam 三选一。
Miro 模板和插件生态最厚；Mural 的工作坊流程引导更强；FigJam 只在你的团队已经用 Figma 时才最优。
理清一个复杂问题的思路
Xmind 或 MindNode。
Xmind 功能全、跨平台、能出甘特/时间线；MindNode 是 Apple 生态里最顺手的，极简但只能 Mac/iOS。
网站改版的页面结构和内容盘点
FlowMapp 或 Octopus.do。
FlowMapp 能把站点图、线框、报价串成一份提案；Octopus.do 更轻、更快出图。要爬现有站点做盘点，用 DYNO Mapper。
写 PPT 时从一段文字快速变出配图
Napkin。
它的产品定义就是"把文字变成可编辑的视觉"，输出能进 PPT。学术图/图形摘要则用 ExplainViz。
把白板能力嵌进自己的产品
tldraw 或 Excalidraw。
tldraw 是 SDK-first 的产品，文档和 API 面向集成；Excalidraw 开源可改，但要自己搭协作后端。
